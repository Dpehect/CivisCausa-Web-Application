# Civis Causa | Next-Gen Human Rights Archive

[https://civiscausa.org](https://civiscausa.org)

Civis Causa is a high-performance editorial digital archive portal that documents human rights violations worldwide through a data-driven approach. Capable of processing tens of thousands of case files with millisecond speed, this platform combines "Big Data" analytics with modern web aesthetics.

## Project Purpose

The primary goal of the platform is to create a permanent and accessible memory by systematically transferring human rights violations, testimonies, and legal processes into the digital environment.

*   **Transparency:** Making human rights violations visible through data-driven analysis.
*   **Speed and Accessibility:** Providing massive datasets (50,000+ cases) to the user without any freezing or latency (0ms latency).
*   **Editorial Aesthetics:** Presenting information with a deep-dark editorial design that respects the gravity of the cases while remaining user-friendly.

## Technologies Used

The project is built on the most performant tools of the modern web ecosystem:

*   **Core:** Next.js 15+ (App Router) and React 19
*   **Language:** TypeScript
*   **Performance Layer:** 
    *   **Virtual Scrolling:** A virtual scrolling mechanism that renders tens of thousands of rows without taxing the browser.
    *   **Web Workers:** Background processing that separates heavy operations like searching and filtering from the main thread.
    *   **Canvas API:** GPU-accelerated graphics for data visualizations.
*   **State Management:** Zustand (Lightweight and fast state management)
*   **Style Management:** Vanilla Extract (Zero-runtime CSS) and Styled Components
*   **Animation:** Framer Motion (60 FPS smooth transitions)
*   **Data Visualization:** D3.js
*   **Icon Set:** Lucide React

## Setup and Installation

Follow the steps below to set up the development environment locally:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Once installation is complete, you can access the project at [http://localhost:3000](http://localhost:3000).

# Civis Causa | Yeni Nesil İnsan Hakları Arşivi

[https://civiscausa.org](https://civiscausa.org)

Civis Causa, dünya genelindeki insan hakları ihlallerini veri odaklı bir yaklaşımla belgeleyen, yüksek performanslı ve editoryal bir dijital arşiv portalıdır. On binlerce vaka dosyasını milisaniye hızında işleyebilen bu platform, "Büyük Veri" (Big Data) analitiğini modern web estetiğiyle birleştirir.

## Projenin Amacı

Platformun temel amacı; insan hakları ihlallerini, tanıklıkları ve hukuki süreçleri sistematik bir şekilde dijital ortama aktararak kalıcı ve erişilebilir bir hafıza oluşturmaktır.

*   **Şeffaflık:** Veriye dayalı analizlerle hak ihlallerini görünür kılmak.
*   **Hız ve Erişilebilirlik:** Devasa veri setlerini (50,000+ vaka) herhangi bir donma veya gecikme (0ms latency) olmadan kullanıcıya sunmak.
*   **Editoryal Estetik:** Bilgiyi, kullanıcıyı yormayan ancak vakanın ağırlığını hissettiren derin ve karanlık (deep-dark) bir editoryal tasarımla sunmak.

## Kullanılan Teknolojiler

Proje, modern web ekosisteminin en performanslı araçları üzerine inşa edilmiştir:

*   **Çekirdek:** Next.js 15+ (App Router) ve React 19
*   **Dil:** TypeScript
*   **Performans Katmanı:** 
    *   **Virtual Scrolling:** On binlerce satırı tarayıcıyı yormadan render eden sanal kaydırma mekanizması.
    *   **Web Workers:** Arama ve filtreleme gibi ağır işlemleri ana thread'den ayıran arkaplan işleme.
    *   **Canvas API:** Veri görselleştirmeleri için GPU hızlandırmalı grafikler.
*   **Durum Yönetimi:** Zustand (Hafif ve hızlı durum yönetimi)
*   **Stil Yönetimi:** Vanilla Extract (Sıfır çalışma zamanı CSS) ve Styled Components
*   **Animasyon:** Framer Motion (60 FPS pürüzsüz geçişler)
*   **Veri Görselleştirme:** D3.js
*   **İkon Seti:** Lucide React
